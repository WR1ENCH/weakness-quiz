# weakness-quiz

让 agent 具备「分析错题 → 定位薄弱点 → 联网搜同类题 → 生成标准练习卷 PDF」的能力。

## 这是什么

一个可复用的 agent skill。给它一份错题本（PDF / 文本），它会：

1. 归类并诊断薄弱点（具体到可检索的知识点短语）
2. 联网检索对应的同类题目（**原样收录，不改数字、不改选项**）
3. 套用标准灰阶试卷模板，生成一份 4 页的针对性练习卷 PDF，最后一页附完整答案解析

排版与样卷完全一致：竖排密封线、卷头、得分总表、大题头、作答区，题型配比固定为 25 / 15 / 20 / 40 = 100 分。

## 目录

```
weakness-quiz/
├── SKILL.md                # 流水线指令：分析 → 搜题 → 出卷 → 质检
└── assets/
    └── exam_template.html   # 灰阶标准卷 HTML 骨架
```

## 使用方法

将本目录作为 skill 加载到 agent 运行时，触发条件：用户上传错题本并表达「分析弱点 / 出练习卷 / 针对性练习」等意图。

流水线由 `SKILL.md` 定义，依赖 PDF skill 的创建流程（`html_to_pdf` + `check_render_quality.js`）。

## 示例

输入：物理静电场错题本（19 道错题）
输出：定位「场强叠加 / 库仑力动力学 / 电场线」三个薄弱点 → 检索同类题 → 生成《静电场（电场力的性质）专项突破练习卷》4 页 PDF + 答案页

## 设计原则（不可变更）

- 题目原样收录，不改数字、不改选项；无可靠答案的题目弃用换题
- 始终附答案解析页
- 排版锁定标准卷样式，不自行更换配色版式
- 题型配比 25/15/20/40 = 100 分，大题附薄弱点标签
